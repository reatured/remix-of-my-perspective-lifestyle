# Lingyi Zhou — Portfolio

A multidisciplinary design portfolio built with Vite, React, TypeScript, and Tailwind CSS.

## Getting started

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Deploy (Vercel)

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

If you use environment variables, add them in Vercel Project Settings.

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui
